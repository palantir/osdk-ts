Functions

Execute Foundry functions (queries) with executeFunction, pass objects and object sets as parameters, and read struct, object, and object set results.

Foundry docsFunctions

Functions published to the Ontology, called queries in the API, appear in your generated SDK next to object types and actions. client(myFunction).executeFunction(params) runs one on the server and resolves to its typed return value.

The samples use these functions, which stand in for functions in your own SDK:

Execute a function

executeFunction takes one object with a key per parameter, or no argument when the function has no parameters. Nullable parameters are optional. It rejects with a PalantirApiError when the function fails or times out on the server; see Errors.

If your SDK was generated with a pinned function version, the client calls that version. Otherwise it calls the latest published version.

Parameter values

Parameter typePass
PrimitiveA value of the parameter's TypeScript type. Dates and timestamps are ISO 8601 strings. long accepts a number or a string.
ObjectA loaded object, its primary key, or { $apiName, $primaryKey }.
InterfaceAn object loaded through the interface, or { $objectType, $primaryKey }, where $objectType is the concrete object type.
Object setAn object set, such as client(Employee).where({ ... }). The server receives its definition, not its objects.
List, setAn array, or a Set for set parameters.
StructAn object whose keys are the struct's fields.
MapAn object keyed by the map's keys. For object keys, use each object's $objectSpecifier.
AttachmentAn attachment RID, a File, or the result of createAttachmentUpload. The client uploads it first.
Media referenceA MediaUpload, a Media from an object, or a MediaReference.
