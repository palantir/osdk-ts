Look up the exact signature, options, and return type of each public API. Most option and return tables are generated from the TypeScript source and its JSDoc; a page says so when a table is written by hand. For walkthroughs, follow the "See also" links on each page.

## `@osdk/react`

| API | Description |
| --- | --- |
| [`OsdkProvider`](./react/osdk-provider.mdx) | Shares a client and its cache with the hooks below it. |
| [`useOsdkObjects`](./react/use-osdk-objects.mdx) | Loads a list of objects of one type or interface. |
| [`useOsdkObject`](./react/use-osdk-object.mdx) | Loads one object by primary key, or observes an instance. |
| [`useLinks`](./react/use-links.mdx) | Loads the objects linked from one or more objects. |
| [`useObjectSet`](./react/use-object-set.mdx) | Loads a list from an `ObjectSet`, with set operations and pivots. |
| [`useStableObjectSet`](./react/use-stable-object-set.mdx) | Keeps an `ObjectSet` referentially stable across renders. |
| [`useOsdkAggregation`](./react/use-osdk-aggregation.mdx) | Runs a server-side aggregation. |
| [`useOsdkFunction`](./react/use-osdk-function.mdx) | Executes a function and caches the result. |
| [`useOsdkFunctions`](./react/use-osdk-functions.mdx) | Executes several functions from one hook. |
| [`useOsdkAction`](./react/use-osdk-action.mdx) | Applies or validates an action. |
| [`useDebouncedCallback`](./react/use-debounced-callback.mdx) | Debounces a callback, with cancel and flush. |
| [`useOsdkMetadata`](./react/use-osdk-metadata.mdx) | Fetches metadata for an object type, interface, or action. |
| [`useOsdkClient`](./react/use-osdk-client.mdx) | Returns the `Client` from `OsdkProvider`. |
| [`useObservableClient`](./react/use-observable-client.mdx) | Returns the `ObservableClient` that backs the cache. |
| [`@osdk/react/testing`](./react/testing.mdx) | `TestOsdkProvider` and `fakeObservableClient` for unit tests. |
